# PALIMPSEST / «Палимпсест»

> Социальная платформа о реставрации искусства: восстанавливай картины, возвращай им историю, строй мастерские. Каждый артефакт — со своей Книгой Слоёв (on-chain провенанс), каждый мастер — с репутацией, которую нельзя купить.

Ядро геймплея — форк открытого проекта [google/restory](https://github.com/google/restory) (Apache License 2.0): мобильные мини-игры про снятие лака, починку холста и подкраску утрат.

## Быстрый старт

```bash
npm install        # рабочие пространства, без внешних зависимостей
npm test           # 53 теста: детерминизм, необратимость, API, античит, Книга, главы, DAO
npm start          # сервер + веб-демо на http://localhost:8787
# PORT=8888 npm start   — если порт 8787 уже занят
```

Веб-демо — играбельный вертикальный срез: заказ дня, диагностика, инструменты реставрации, «Акт реставрации» с Индексом Палимпсеста, лидерборд и Книга Слоёв. Демо исполняет **ту же** симуляцию, что и сервер (клиент генерирует пазл из сида, сервер переигрывает без доверия). Картина показана живописным видом: реалистичные утраты, разрывы, кракелюр и грязь лака поверх полотна эпохи (кнопка «вид: канон» — канонический кадр, «Око мастера» — диагностическая подсветка).

Unity-клиент (форк Restory):

```bash
bash scripts/integrate-upstream.sh
# фетчит upstream на пине 67b94f1, собирает форк в third_party/restory:
#   Assets/Scripts/Palimpsest/  — модули платформы (симуляция, мост, хук)
#   declareFInishController.cs  — патч с пометкой «Modified by…» (Apache 2.0 §4(b))
#   PALIMPSEST_NOTICE.txt       — атрибуция внутри форка
# детали: client/unity/INTEGRATION.md
```

Хранилище: по умолчанию JSON-снапшот; для PostgreSQL задайте `DATABASE_URL`
(схема `packages/server/src/schema.sql`, тесты на PGlite). Запись Книги в
Solana — `CHAIN_MODE=solana` + переменные из `chain/README.md`.

## Принципы (из концепции)

* **Необратимость**: каждое действие нельзя отменить — серверная переигровка делает это честным, а не жестоким.
* **Книга Слоёв**: историю нельзя переписать — только дописать (append-only, mock-цепочка или Solana).
* **Solana** — про владение, провенанс и проверяемость: без токена, без доходности, без pay-to-win.
* **Невидимый Web3**: игра полноценна без кошелька; on-chain запись — от платформы (gasless).

## Статус

Discovery → Prototyped → **Alpha/Beta закрыты, слой Soft Launch реализован**: симуляция и сервер, форк Restory с телеметрией, «Дыхание времени», cNFT (Metaplex Bubblegum), Книга Слоёв, Аттестат и его иерархия, Заказ дня, Мастерские, Вернисаж, Тихий торг (казна 50/30/20), Пентименто, турниры (Дуэль/Триптих, равный старт, призы без взносов), Манифест сезона (Battle Pass без pay-to-win), канонический пазл из сида в Unity (v2), нарративные главы сезона (I «Великое Потемнение» — VI «Пентименто»: заказ недели + квесты + ротация через DAO), галерейный вид акта, каталог наград, рамы-оклады и темы-скины по факту владения, Rewarded-видео (только Пигменты, лимит/день), proto-DAO Мастерских (управление сезоном: тема главы, казна турниров), боевой PostgreSQL-путь (PGlite-интеграция). Дальше — новые главы и расширение контента по дорожной карте CONCEPT.md (§10).
